How to Update the Homepage

  1. Fill in each event above and click Generate HTML
  2. Copy the generated code from the output box
  3. Open index.html in a text editor (Notepad, TextEdit, VS Code)
  4. Find the comment <!-- EVENT CARDS START and replace all the event card divs below it with your copied HTML
  5. Save the file, then drag the entire bcoe_site folder to Netlify to redeploy
💡 Tip: The homepage shows 3 events side-by-side. Generate 3 events and paste all 3 into the grid for the best look. You can generate one at a time and copy each.
